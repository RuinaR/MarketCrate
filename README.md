# MarketCrate

Windows 10/11 · C# / .NET 10 / WPF / MVVM 기반 Steam 보관함·판매 계획 앱의 **최초 Mock 구현**입니다. Steam 공식 앱이 아닙니다.

**필수 최종 목표:** 최종 검토에서 `전체 판매등록`을 한 번 승인하면 선택 전 품목·수량·개별 가격을 실제 Steam 장터에 제출합니다. 현재는 **LIVE_INTEGRATION_BLOCKED**이며 실판매 지원 완료가 아닙니다. 허용된 경로가 확인되지 않은 읽기·등록·취소·재등록은 구현/활성화하지 않았습니다.

## 현재 기능

- 합성 게임별 보관함, 검색·정렬, marketable/tradable/보류 구분, 전체 선택·수량 편집, 카드/가상화 목록 전환.
- 24시간 거래량 가중 평균과 구매주문 잔량별 예상가 분리. 검토표에서 가격별 수량·단가·수수료·실수령·시각 표시 및 가격 편집.
- `Mock 배치 전체 실행` 한 번으로 전체 스냅샷 처리. 부분 실패·접수·승인 대기 표시, 중복 클릭 차단, 디스크 저널 복구·상태 대조. 불명 상태는 자동 재전송하지 않음.
- 독자적인 다크 테마/커스텀 템플릿. 모션 축소 기본 ON. 앱 외부 입력·프로세스 조회·포커스 강탈·자동 시작·네트워크·계정 연결 없음.

## 빌드와 테스트

설치된 .NET SDK 10.0.301 및 Windows Desktop 참조 팩을 사용합니다. 외부 NuGet 패키지/온라인 복원은 없습니다. 저장소 루트에서:

```powershell
./scripts/Verify.ps1
```

테스트는 외부 테스트 프레임워크가 필요 없는 콘솔 assertion runner입니다. `dotnet test`가 아닌 위 스크립트가 실제 검사를 실행하며 실패 시 종료 코드 1입니다. 합성 데이터만 `runtime/tests-*`에 생성·삭제하고 GUI/Steam/네트워크를 사용하지 않습니다.

앱 실행은 사용자가 허용하는 시점에 `src/MarketCrate.App/bin/Debug/net10.0-windows/MarketCrate.App.exe`를 직접 실행할 수 있습니다. 개발 중에는 앱을 실행하지 않았습니다. 생성물은 Git에 포함하지 않습니다.

## 제한과 다음 단계

- GUI 런타임, hover·키보드·스크린리더·DPI·리사이즈는 **NOT VERIFIED**. 빌드와 ViewModel 테스트만으로 UI 품질 완료를 주장하지 않습니다.
- 카드 WrapPanel은 소량 Mock용이며 대량 가상화는 목록 모드만 구현했습니다. 대량 카드/범위 선택·드래그, 상세 취소·가격 변경 대화상자는 남아 있습니다.
- KRW 정수 수수료는 **Demo 추정 정책**입니다. 실제 Steam 통화별 수수료·호가 매칭은 미검증이며 체결을 보장하지 않습니다.
- SQLite 대신 합성 데이터 전용 원자적 JSON 저널을 먼저 구현했습니다. 스키마 v1 외에는 차단합니다. 실제 데이터 저장·SQLite 마이그레이션은 후속 작업입니다.
- 단일 활성 Mock 배치만 보존합니다. 재시작/취소 후 미전송 건도 자동 재개하지 않습니다. `합성 Mock 기록 삭제 / 새 배치`는 데모 기록만 삭제합니다. 실거래 어댑터에 이 동작을 재사용해서는 안 됩니다.
- 공식 서버 증거가 없는 Mock 복구 결과는 `Unknown`이며 승인·게시를 자동으로 만들어내지 않습니다.
- 앱의 합성 저널은 `%LOCALAPPDATA%/MarketCrate/Demo`에 저장합니다. 다른 인스턴스가 저널을 사용 중이면 두 번째 앱은 종료 코드 2로 종료합니다.
- 실연동 허용 근거·명시적 옵트인·별도 실제 검증 없이는 LIVE_READY/RELEASE_READY가 아닙니다. 계정 제재 위험 0을 보장하지 않습니다.
