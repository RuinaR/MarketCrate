## 0.23.0 표시·아이콘·조회 보완

상단 ‘Steam 지갑’은 별도 서버 잔액이다. 목록 우상단의 합계는 현재 검색/필터 결과 중 확인된 수량의 구매자 금액이며 수수료 차감 전이다. 포함·제외 항목 수를 표시하며 미확인/부족 수량을 합계에 넣지 않는다. 행에서 ‘평가’ 대신 수량별 금액 합계를 표시한다. 정확한 등급·변형명이 있어 같은 이름의 다른 상품과 비교할 수 있다.

전체/장비/재료/기타 필터와 잠금/장착 포함을 조합한다. 가격 있는 항목만 단가순이며 미확인 항목은 별도의 순위 없음 그룹이다. 일부 품목의 조회 실패는 다른 품목의 조회를 막지 않는다(인증/403/429/Challenge/안전 차단·연속 형식 오류는 중단). 오류를 빈 주문으로 바꾸지 않는다. 다시 갱신은 새 사용자 요청이며 자동 반복하지 않는다.

보관함/판매목록 이미지가 없어도 실현된 행의 정확한 공개 상품 metadata를 조회한다. 같은 게임 sprite/name의 대표 아이콘일 때는 툴팁으로 구별하며, 그 대표 상품의 가격을 원래 아이템 가격으로 대체하지 않는다. 장터 상품이 없거나 공개 metadata 접근이 불가능한 품목의 이미지는 여전히 없을 수 있다. 이미지OFF/화면 이동/재활용/종료는 기존 취소를 사용한다. 아래0.21의 ‘이미 조회된 Steam 자산만 아이콘’ 제한은 이 구현으로 대체됐다.

# TBH 게임 아이템 평가 — 0.21.0

## 사용법

`게임 아이템`은 Steam 자산 목록과 별개다. 세이브 복사·읽기 → 필요하면 잠금/장착 포함 → Steam 계정 연결 → 장터 가격 갱신 순서로 사용한다. 새로 저장하지 않은 게임 상태는 파일에 반영되지 않을 수 있다. 자동 감시나 가격 폴링은 하지 않는다.

기본 경로는 `%USERPROFILE%/AppData/LocalLow/TesseractStudio/TaskbarHero/SaveFile_Live.es3`다. 파일을 읽기 전용/공유 모드로 두 번 메모리에 복사해 내용 해시와 수정 시각이 일치할 때만 분석한다. 최대20MiB, 변경 중에는 최대3번만 복사하고 실패한다. 원본·다른 사용자 파일·게임 프로세스·설치 파일은 수정/조회하지 않는다. 복호화 파일은 저장하거나 업로드하지 않는다. 읽기 실패 시 이전 목록을 유지한다.

## 위치·잠금·장착

| 저장 구역 | 처리 |
|---|---|
| stashSaveDatas | 창고 탭/열/행, 공개 레퍼런스의7×7 기준을 명시 |
| inventorySaveDatas | 가방 슬롯 번호, 확인되지 않은 행/열은 생성하지 않음 |
| materialStashSaveDatas | 신규 **재료창고**. ItemKey/ItemUniqueId/Quantity 교차 검증,0수량 슬롯 제외. 좌표 필드 없음 |
| heroSaveDatas | 영웅 키/장비 슬롯, 장착 포함 체크로 별도 제어 |
| trading/remakeTradingStashSaveDatas | 거래 선적 표시, 이동 상태 불확실하므로 평가 제외 |

아이템/슬롯 잠금 중 하나라도 잠기면 잠금 상태다. 잠금/장착 기본OFF이고 잠긴 장착품은 두 체크를 모두 켜야 보인다. 동일 고유 ID가 여러 위치에 등장하면 양쪽에 중복/미확인 표시하되 가격 합산에서는 제외한다. 재료창고도 같은 중복 규칙을 사용한다. 누락된 소유 참조/서로 다른 ItemKey는 오류이며 빈 목록으로 꾸미지 않는다.

## 가격·이미지

- 즉시거래가능가: 기존 Steam 주문장 어댑터의 높은 매수주문부터 배분한다. 동일 상품은 창고가 달라도 잔량을 공유한다. 부족 수량은 미평가로 표시한다. 필터에 포함한 대상의 잔량을 다시 배분한다.
- 최저 판매주문호가: 현재 공개 최저 판매 주문의 구매자 금액으로 평가한다. 이 **조회 전용 평가 화면**은 본인 물량을 차감하지 않는다. 실제 판매/재등록 화면은 기존처럼 본인 현재 게시 수량을 제외한 경쟁 호가를 사용한다.
- 표시 금액은 **구매자 호가 기준·수수료 차감 전 평가액**이다. 실제 실수령/체결/판매 가능/현재 보유 보장이 아니다. 통화별로 합산하며 섞어서 더하지 않는다. 단가 내림차순, 같은 단가는 평가액/이름순이다.
- 가격은 사용자 명시 요청만, 회당 최대200종·기존 직렬 요청 제한·5분 메모리 캐시·최대512종을 사용한다. 실패/403/429/인증 요구를 우회하거나 자동 재시도하지 않는다. 완료한 시세는 유지하고 실패를0원으로 바꾸지 않는다. 로그아웃/연결 변경 시 캐시를 버린다.
- 공개 키/영문명/등급 사실 메타데이터6503행을 포함한다. 시장 이름의 후보 매핑은 실제 서버 호가 응답으로 확인한다. 미등록 유물/새 키/비거래품은 매핑 없음으로 남긴다. 등급 A/B/C는 같은 이름·등급 그룹의 키 순서를 대조했지만 모든 품목의 실서버 대응을 검증한 것은 아니다.
- 아이콘은 이미 조회한 TBH Steam 보관함/판매목록에서 같은 상품의 검증 CDN 메타데이터가 있을 때만 재사용한다. 전체 게임 아이콘 세트를 복사하거나 게임 설치 파일에서 추출하지 않는다. 메타데이터가 없으면 `—`를 표시한다. 전체 게임 품목의 아이콘은 미완성 범위다.

## 판매와 구분

세이브 고유 ID는 Steam asset ID가 아니다. 이 화면은 판매 요청/취소/SQLite intent를 만들지 않는다. 판매는 Steam 보관함에서 실제 asset/marketable/수량/통화/수수료를 다시 확인한 뒤 기존 단일 최종 승인으로만 실행한다. 하향 옵션은1원을 고정 차감하지 않고 이전 유효 가격을 사용한다. 두 가격 기준의 검토와 재등록 비교에 구매자 기준 인하액, Steam/게임 수수료, 실수령 감소를 표시하며 최저 유효가에서는 인하0으로 유지한다.

## 검증 범위

지정된 실제 로컬 파일의 읽기/복호화/재료창고 구조/참조 분석 성공은 확인했다. 원문/개인 자산 데이터는 테스트 fixture·Git·진단 ZIP에 넣지 않았다. 가격/판매 경계는 합성 HTTP로 검증하며 새 실제 Steam 시세/거래/물리 입력/장시간 실행/게임 저장과의 모든 경합은 미검증이다. 임의의 시점에 게임 파일이 원자적으로 저장된다고 보장하지 않는다.
