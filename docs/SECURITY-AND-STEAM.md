### 시작 시 자동 로그인에 대한 별도 판단

## 0.20 권한 분리

## 0.18 수수료·제품화 경계

공식 공개 JS의 실제 조건을 따르는 독립 C# resolver를 추가했으며 해당 JS를 재배포하거나 브라우저/Steam에 주입하지 않는다. 새 인증 추출/Node runtime/AGPL 코드 도입0. FeeContext는 인증된 본인 프로필 inventory HTML의 정확한 경로만 허용하며 목적지 변경/403/429/Challenge는 우회하지 않는다. HTTP 원문/props/QR/토큰/쿠키/계정 ID는 로그에 남기지 않는다.

사용자 수기 공식 금액은 비교 자료이고 서버 계약/거래 권한이 아니다. 첫 판매의 과거 등록 조건은 공식 서버 모드/앱·자산 수수료 검증으로 대체했으며 무조건 활성화한 것이 아니다. 불명 모드·통화·스택/반환·수수료는 계속 차단한다. 기존 인증 저장/저널은 그대로이며 세션 복원이 자동 판매나 거래 활성화로 이어지지 않는다.

실제 계정/거래·GUI/다른 프로세스·화면/전역 입력/호스트 설정 접근0. 비공식 자동화의 Valve 허가/제재 위험0을 주장하지 않는다. 현재 REAL_FEE_VERIFIED/LIVE_SELL_VERIFIED/RELEASE_READY는 미달이다.


## 16차 명시적 저장 예외와 보안 한계

이전 '인증정보 디스크 미저장' 규칙에는 사용자 명시 요청으로 로그인 유지 예외를 추가했다. **자체 QR에서 받은 WebBrowser Refresh Token만**, 명시적 선택 후 DPAPI CurrentUser·사용자 전용 ACL로 Auth 영역에 저장한다. Steam 클라이언트/브라우저 세션·쿠키·자격증명 저장소·Guard 비밀을 가져오는 예외는 아니다. 저장/복원/삭제 정책은 AGENTS16차와 SESSION-PERSISTENCE가 현재 기준이다.

최소 저장 버전/Windows SID/계정/동의/토큰/만료·확인시각은 암호문 안에 있으며, public .ToString/진단/ZIP/SQLite/환경변수/배포에서 비밀값을 제외한다. 손상/미완료 파일을 정상 빈 상태로 복구하지 않는다. 네트워크 전에 복원 차단 표식을 flush하고, 실패 후 자동 반복이나 과거 토큰 fallback이 없다. 새 파일 저장 전 원래 암호문 지문을 대조해 다른 인스턴스의 삭제를 되살리지 않는다.

같은 Windows 사용자 악성코드·관리자·이미 읽힌 프로세스 메모리의 비밀까지 DPAPI가 차단한다고 주장하지 않는다. .NET/HTTP/JSON immutable string 잔류 가능성이 있어 완전한 메모리 제로화를 보장하지 않으며 앱은 덤프를 만들지 않는다. 실제 다른 Windows 사용자/전원차단/실계정 서버 만료·회전·철회 시험은 미실행이다. 로컬 삭제는 서버 철회와 다르다. 실거래는 실행마다 OFF이며 인증 유지와 거래 승인/저널 복구는 분리된다. 타 프로세스/Steam 클라이언트/데스크톱 입력·화면·시스템 설정 접근0을 유지한다.

## 7차 추가 경계

ImageCache는 Steam 인증 client와 완전히 분리된 무쿠키/무권한·referrer·redirect/proxy OFF, 단일 확인 CDN/고정 경로다. opt-in과 실현된 컨트롤 구독만 내려받고 unload/재활용/로그아웃 취소, 범위·용량·시간·403/429 latch 제한을 적용했다. URL/토큰/bytes는 로그·journal에 저장하지 않는다. 실제 이미지서버 확인/위험0 보장 아님.

- Steam Guard 승인 자동화 없이 공식 모바일 앱에서 직접 승인. 대기 상태인 아이템을 `판매 등록 완료`로 표시하지 않는다.
- 데이터 조회는 허용된 방식만 사용하고 요청 캐시·보수적 속도제한·동시성 제한·중단/백오프. 오류 403/429, 차단·캡차는 우회하지 않음.
- 실등록/취소·재등록은 **Valve가 허용한 방식과 권한을 확인한 뒤에만** 활성화한다. UI에서 전체 판매등록 요청 하나로 전체 항목을 처리한다는 요구는 고정하되, 승인되지 않은 비공식 POST를 안전하다고 속이지 않는다.
- 탐지 회피(랜덤 행동·사람 흉내·프록시 회전·계정 분산·요청 위장) 금지. 정책과 별개로 제재 위험 0 보장 금지.

- 실전 모드의 버튼은 최종 검토에서 승인할 때만 실제 제출. 자동 실행/자동 재등록/자동 시세에 따라 거래 결정 금지.
- 스냅샷 고정, 입력값 검증, 이중 클릭·재시도 중복 등록 방지, 부분 성공/타임아웃/불명 상태를 저널에 기록하고 재조회 후 조정.

- `배치 요청을 보냈다` vs `Steam에서 게시되었다` vs `판매 체결되었다`를 서로 다른 상태로 표시.
